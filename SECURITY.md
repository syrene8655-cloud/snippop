# Reporting a security issue

Please email **syrene8655@gmail.com** with the subject **SnipPop security report**.

Include the affected app version, a description of the issue, and safe reproduction steps. Please do not publish an exploit or sensitive data in a public GitHub issue. Do not send live credentials, license keys, payment information, or other users' private data.

This repository contains public product documentation. The SnipPop application is distributed through [snippop.cc](https://snippop.cc/en/).
