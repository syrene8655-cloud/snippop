# SnipPop · 截图泡泡

让 Mac 截图随手可用：截图保存后显示为悬浮预览，可以固定、标注、打码、提取文字、压缩，以及拖进其他应用。

[官网下载与试用](https://snippop.cc/zh-cn/#download) · [English](README.md)

## 这个仓库的用途

这里用于维护 SnipPop 的公开介绍、使用说明、版本记录，以及收集问题和建议。**SnipPop 是收费的闭源软件，这里不提供应用源码和安装包。** 请从官网下载正式版本。

## 系统要求

Apple silicon 芯片的 Mac，macOS 13 或以上。目前没有 Intel 版本。界面支持英语、简体中文、繁体中文、日语和韩语。

## 使用与隐私

支持 macOS 保存为文件的截图；仅复制到剪贴板的截图不会自动生成泡泡。最多显示 14 个图片或视频预览（包含固定项）。关闭泡泡不会删除原文件。

截图编辑和 OCR 在本机完成，不上传截图进行处理或云同步。支付与授权需要使用在线服务。把图片分享给其他应用后，适用对方应用的处理方式和隐私政策。
